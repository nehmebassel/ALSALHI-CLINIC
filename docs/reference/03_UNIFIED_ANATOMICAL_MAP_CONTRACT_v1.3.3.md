# Unified Anatomical Map Contract — v1.3.3

## نموذج واحد

- خريطة فروة رأس واحدة ومحايدة لجميع المراجعين.
- الاتجاهات: `Front`, `Top`, `Right side`, `Left side`.
- لا يوجد نموذج منفصل حسب الجنس.
- `Facial Hair Areas` جزء اختياري من الخريطة نفسها، وحالته الافتراضية `OFF`.
- التفعيل يدوي من الطبيب عند الحاجة؛ لا تفعيل تلقائيًا بناءً على الجنس.

## حدود السجل

- لكل زيارة Map ID وإصدار مستقلان.
- الحفظ يربط العلامة/الملاحظة بالزيارة والطبيب والوقت والمصدر.
- Finalized يجعل النسخة Read-only.
- Reasoned Amendment ينشئ نسخة لاحقة مع actor + timestamp + provenance؛ لا يستبدل النسخة السابقة.
- المقارنة تعرض خريطتي زيارتين جنبًا إلى جنب؛ لا دمج ولا رسم فوق نسخة سابقة.

## Journey

الخريطة لا تظهر داخل المحور الرقمي. Visit marker قد يعرض مؤشرًا صغيرًا بأن للزيارة خريطة؛ الضغط يفتح سجل الزيارة/الخريطة.
